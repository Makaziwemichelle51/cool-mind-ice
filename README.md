# IceFlow AI

Build an AI-Powered Ice Cube Business Website

Create a modern, professional, responsive business website for an ice cube company called [Business Name]. The website should combine an ice cube ordering business with an integrated AI Workplace Productivity Assistant.

The website must have a professional, clean, modern UI/UX and work seamlessly on both desktop and mobile devices.

1. Homepage / Dashboard

Create a professional dashboard-style homepage with:

Business logo and name

Navigation sidebar

Welcome section

Ice cube products and ordering

AI productivity tools

Recent activity

Quick action buttons

Responsive mobile navigation

The sidebar should contain:

Dashboard

Ice Products

Orders

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner

Settings
